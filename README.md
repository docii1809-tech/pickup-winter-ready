# Pickup Winter Ready

A mobile-first static affiliate-content website starter for winter pickup-truck gear.

## Included
- Responsive homepage and navigation
- Interactive general-purpose gear finder (no AI/API required)
- Buying guides for jump starters, tire inflators, and recovery equipment
- Winter checklist
- Affiliate disclosure and privacy information
- Search metadata, robots.txt, sitemap.xml
- Affiliate link configuration file

## Important: affiliate links are not connected yet
Open `affiliate-config.js` and paste your own complete tracked URLs:
- Amazon Special Links generated inside your Amazon Associates account
- eBay tracked links generated inside eBay Partner Network

Do not paste account passwords, API keys, or other secrets. Do not replace the Amazon/eBay disclosures with a footer-only notice. Disclosures are shown near the shopping area and site-wide.

The buttons intentionally remain disabled/placeholders until valid tracked URLs are supplied. This prevents accidentally sending visitors to untracked links and falsely implying that commissions are being earned.

## Preview
Open `index.html` in a browser. All core content and the finder work locally. Google Fonts are optional; the site falls back to system fonts if offline.

## Deploy free with GitHub Pages
1. Upload the contents of this folder to the root of a GitHub repository (not the ZIP file itself).
2. In GitHub, open Settings → Pages.
3. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.
4. After publishing, replace the placeholder canonical URL in `index.html` and the sitemap URL with the actual GitHub Pages URL or your own domain.
5. Add your final site URL to your Amazon Associates account's website list if required by your account settings. Confirm that your promotional method and content meet the current program policies before using links.

## Editorial and safety notes
This site does not claim to have physically tested products. Manufacturer specifications are not independent test results. Prices, availability, product models, and seller terms change. Always verify compatibility for the exact vehicle and follow the owner's manual and equipment instructions. This site is general shopping information, not a diagnosis or substitute for professional mechanical or recovery advice.

## No cost / no backend
This version uses HTML, CSS, and vanilla JavaScript. It has no paid API, database, analytics, contact form, server, or recurring service dependency. GitHub Pages can host the static files for free subject to GitHub's current terms and limits.
